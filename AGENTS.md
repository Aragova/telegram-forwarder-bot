## Логи и тексты

- Все сообщения Telegram-бота для пользователя — на русском языке.
- Исключение: существующий публичный сайт `landing/` поддерживает RU/EN; все новые видимые тексты на этом сайте должны быть переведены для обеих локалей с использованием существующего `data-i18n`/`dict`. Нельзя ломать переключатель языка ради правила для Telegram-бота.
- Логи должны быть понятные человеку
- В интерфейсе ошибок доставки показывать русскую причину и безопасное действие через `app/delivery_error_text.py`. Не выводить сырые коды, исключения, стеки и секреты. Внутренние коды в БД и технических журналах сохранять без изменений; при неизвестной причине не выдумывать диагноз.
- Без stack trace в UI

## Порядок проверок PR

- На этапе разработки запускайте CI проекта, SonarCloud, Gemini Code Assist и Codex; устраняйте реальные замечания и повторяйте проверки изменённого HEAD.
- CodeRabbit сохраняет профиль `assertive` и все существующие инструкции. Автоматическое ревью выключено: после прохождения остальных обязательных проверок и стабилизации HEAD запросите полное ревью комментарием `@coderabbitai full review`.
- Не запускайте CodeRabbit на каждом промежуточном коммите. Если после финального ревью код изменён, повторите необходимые проверки, включая CodeRabbit для нового HEAD. Не используйте старые результаты для разрешения слияния.
- До merge убедитесь, что обязательные проверки завершены успешно, замечания разобраны и нет открытых блокирующих проблем. Не обходите защиту веток.
