# Система и биллинг

Админское главное меню содержит «Финансы» вместо устаревшей «Очереди».
«Система» содержит только глобальные запуск/остановку и возврат.
USD, Stars, Crypto и ручные курсы независимы.
Старые финансовые reply/callback сохраняются, управление пересылкой в
личном чате маршрутизируется единственным существующим роутером.
Цены и их аудит сохранены. Экран всех фиксированных цен читает две истории
вместо 16; экран одного тарифа — одну вместо четырёх. Чтения вынесены
из event loop в run_db. Неконечные числовые значения отвергаются.

Планировщик не выполняет бесполезную проверку fairness для репоста и
видео при нормальной нагрузке. При деградации проверяет те же критерии
по актуальным счётчикам heavy одного tenant одним SQL вместо четырёх
обращений; сохраняется проверка подписки и лимитов, атомарный enqueue,
защита от дублей и все глобальные ограничения ресурсов. Синхронные
чтения подписок, top-time guard и запись событий вынесены в поток.
OWNER не превращается в безусловный обход прав, данные не кэшируются
между заданиями. Миграции и удаление SaaS-таблиц не требуются.
