# AI-подпись репостов (пилот)

Включается только администратором на конкретном правиле. По умолчанию AI выключен.
В окружении сервера: VIMI_AI_CAPTION_ENABLED=1, OPENAI_API_KEY (секрет),
VIMI_AI_CAPTION_MODEL (по умолчанию gpt-4o-mini). Не коммитить ключ.
Фото передаются OpenAI API; включать только для материалов с разрешением на такую обработку.
Модель описывает нейтральные видимые детали, не определяет ориентацию/возраст и не генерирует откровенные подписи.
Фото и фотоальбомы проходят модерацию; отказ не переключает отправку на Bot API.
Видео и смешанные альбомы используют исходный режим репоста без AI-подписи.
Оформление: жирный заголовок, реальные Premium Emoji из сохранённого образца подписи, ссылки в MessageEntity.
Обязательные фразы и ссылки хранятся в настройках правила; URL не передаются модели.
Пробный запуск: выбрать AI в «Подпись», задать контекст, часовой пояс, обязательные элементы
(строка текста или название | https://t.me/...), отправить фото в «Тест фото».
Предпросмотр текстовый; фактическое Premium-оформление проверить в закрытом тестовом канале.
При отказе API публикация фото не выполняется. Вернуть прежний режим можно в меню.
Готовая подпись сохраняется в записи попытки доставки до отправки, при повторе используется тот же текст.
Период суток берётся при подготовке; сохранённый текст не меняется ради idempotency.
Не включать до проверки CI, тестового канала, доступности API и лимитов расходов.
