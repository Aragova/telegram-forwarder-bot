# Центр ошибок и карточки правил

Администратор: Диагностика → Центр ошибок / Журнал событий. Старые reply
и inline-кнопки продолжают работать, тестовые styled-кнопки перенаправляются
без тестового функционала. Один владелец callback проблемных доставок.

Центр считает текущие неочищенные faulty-доставки по общему SQL с экраном
ошибок; устаревшие задания по ID по тому же heartbeat/lease предикату, что
ручное восстановление; осиротевшие правила по предикату карантина; текущие
неподтверждённые receipts; активные ограничения с конечным сроком. Последние
включают лимиты Telegram и отдельно подписанные квоты проверок эмодзи.
Бесконечные защитные fence не считаются временными ограничениями и не
удаляются. При ошибке чтения доступны повтор и возврат в центр. Это разные единицы,
поэтому числа нельзя суммировать. Они не заменяют логические позиции правила.
Нет данных — не зелёный статус. Список проблемных доставок показывает
до 200 последних записей; восстановление до 50 заданий за раз; просмотр
receipt/cooldown по 10 строк. Обновление читает актуальную БД.
Никаких изменений схемы БД, повторных отправок из экрана receipts или сброса
ограничений Telegram. Восстановление и карантин сохраняют существующие fence,
подтверждение и проверку снимка. Журнал фильтрует до 300 последних событий
выбранной категории, до пяти событий на страницу с переходами к правилам.
Фильтр публикаций включает этапы доставки и выбор режима подписи.

Карточки: статус, режим доставки, фикс. график или точный интервал; ближайшая
отправка, все фиксированные времена, пустая строка перед статистикой.
Каждый показатель отдельной строкой, HTML rich, без заголовка ПУБЛИКАЦИИ
и без строки внутреннего режима подписи. Настройки подписи и callback-кнопки
не меняются. Длина видео, рекламные сведения и пользовательская приватность
сохраняются. Время показывается с датой, если отправка не сегодня.
