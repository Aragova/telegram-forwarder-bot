# Аудит SonarQube Cloud: ViMi Autoposting

**Источник:** выгрузка SonarQube Cloud от 22.11.2026, 53 открытых замечания.
Анализ сделан до последних изменений в `main`: строки отчёта не всегда
соответствуют актуальному коду.

## Подтверждённые исправления в PR

- Добавлен реестр фоновых задач со строгими ссылками и логированием ошибок
  (парсинг истории, heartbeat и watchdog в UI, scheduler и worker).
- Отмена dashboard и worker корректно пробрасывает `CancelledError`.
- Временные файлы превью создаются в `asyncio.to_thread` с защитой `asyncio.shield`;
  отмена ожидающего вызывающего кода приводит к удалению файла после создания.
  Отмена загрузки из Telegram также удаляет временный файл.
- Экспорт CSV/TXT/XLSX отправляется через `BufferedInputFile` без дискового I/O.
- Соединение PostgreSQL гарантирует rollback также при `BaseException`.
- Убрана одинаковая условная ветка callback-кнопки включения правила.
- Исправлены дубли ключей перевода и `title`/`lang` на HTML предпросмотре.
- В CI допускается только фиксированный `pyaes==1.6.1` из sdist (обязательная зависимость Telethon без колеса); прочие пакеты устанавливаются из wheels. Бесконтрольные апгрейды pip убраны.
- Добавлены регрессионные тесты на фоновое выполнение, отмену и rollback.

## Восемь предупреждений безопасности без подтверждённой эксплуатации

- `S2068` ×5: в `app/reaction_onboarding_server.py` перечислены
  **переводы надписей** с `password`, а не жёстко заданные пароли/токены.
  Не удалять поля интерфейса 2FA.
- `S2083` ×2: `fix_how_css.py` и `fix_how_html.py` записывают локальные
  статические файлы `landing/`; не являются HTTP-обработчиками и не
  принимают пользовательский путь. Для этих конкретных трассировок
  Path Traversal не подтверждён.
- `S5332` ×1: `http://t.me/` в `app/repost_campaign_message_handlers.py`
  распознаётся как введённая пользователем строка и переводится в username;
  **HTTP-запрос не выполняется**. Сохраняем совместимость со ссылками.

## Не менять без отдельного доказательства безопасного рефакторинга

- `S3516` ×6: `True` у message handlers используется как сигнал
  «ввод обработан», а `0` у CLI-ремонтных скриптов как код успеха.
  Отдельный случай в `postgres_repository.py` (миграция) требует проверки
  контрактов до изменения. Поправки «ради рейтинга» здесь опаснее.
- `S8786` ×2: регэкспы нормализации Markdown требуют тестирования
  на длинных строках до изменения семантики подписей.
- `S7484` ×1: 30-секундный watchdog FFmpeg обеспечивает таймаут при
  отсутствии прогресса; перед переходом на Event нужен тест зависания и
  прерывания подпроцесса (см. AGENTS.md).
- `S8544` ×4: `requirements.txt` допускает диапазоны версий.
  `--only-binary=:all:` с единственным исключением `pyaes==1.6.1` снижает риск запуска посторонних build-скриптов, **но не
  заменяет lockfile** с зафиксированными транзитивными зависимостями.
  Lock требует отдельной согласованной сборки для Python 3.11 и 3.12.

## Валидация

- GitHub Actions Smoke Check и Python Tests должны пройти на актуальном HEAD.
- В тестовом боте проверить добавление источников и тем с запуском парсинга.
- Проверить корректное завершение worker при in-flight задачах без дублей.
- Проверить экспорт CSV/TXT/XLSX и FFmpeg thumbnail.
- Старый Sonar отчёт не обновится без нового анализа целевой ветки.
